# 迭代路线

## 已交付 v1

Phase 1 核心：首页与品牌、公开项目 / Skills / 场景目录、OAuth 接口与本地演示身份、开发者主页、投稿审核、用户工作台和运营后台。

Phase 2 基础：外部 Demo、8 篇 MDX 文档、收藏点赞与评论审核、GitHub 同步缓存、签名 Webhook、5 个专题。

Phase 3 基础：共创任务申请、审核、PR 链接、人工确认贡献、公开作品集、企业需求私密队列与脱敏发布。

## 正式运营部署项

这些需要实际外部账号或运营信息，不是本地测试能够替代的：

- 配置 Supabase PostgreSQL、GitHub OAuth、Vercel / Node 托管与域名 DNS。
- 真实 GitHub 身份登录、续期、退出和生产 RLS 联调。
- 补充运营主体、隐私联系人、保留周期和数据请求处理流程。
- 对正式部署环境执行备份恢复、日志与告警演练；在部署机验证 Docker。
- 由维护者核实演示服务实际访问条件与项目兼容版本。

## 后续增强（明确保留边界）

1. **GitHub Issues 自动聚合**：筛选 Good First Issue、仓库 Webhook 异步队列、重试和配额调度；目前支持关联 Issues 链接与 PR 人工确认。
2. **Demo 运行平台**：统一启动协议、额度、沙箱、隔离网络与生命周期；目前只提供外部入口和说明性样例。
3. **Skills CLI**：稳定版本 API、签名包、依赖解析、平台兼容测试；当前只读 API 与结构化元数据为扩展基础。
4. **资源展示**：维护者上传经授权的截图 / 视频、对象存储、文件扫描与删除；当前使用自有图标、正文和原项目链接，不冒用产品截图。
5. **搜索扩展**：大规模中文检索、全文索引排序、专题订阅；当前 SQL 多字段搜索不检索企业原始需求。
6. **运营增强**：更多后台分页与角色分工、企业线索分配 / 阶段、隐私自助导出 / 删除、多渠道通知、事件去重与 UV。
7. **认证与协作**：真实维护者审核凭证、PR 作者自动匹配、组织身份、多贡献者项目与审核队列分工。
8. **生产加固**：nonce CSP、更多滥用检测、轮换密钥、审计日志外存与保留周期任务。
9. **支付**：悬赏支付与资金托管属于独立后续版本，本次没有收款能力。

## 内容增长

围绕「100 个企业 AI 开源实战项目共建计划」优先积累可复现资产：部署记录、失败案例、合成评测、行业方案与可核验贡献。公开内容保持开放，课程和商业合作明确分离。暂不增加复杂论坛、虚构活跃度或强制注册阅读门槛。
