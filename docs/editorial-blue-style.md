# 资讯媒体蓝色视觉版

2026-11-19，按用户希望接近36氪风格的要求，调整现有网站的配色与视觉层次。

参考了可访问的[36氪官方关于页面](https://www.36kr.com/pages/about)及其公开样式，确认其使用 `#4285F4` 强调色。未复制36氪Logo、文章、图片或导航品牌。首页直连触发访问检测，因此不声称完整复刻其当前首页。

| 用途                           | 颜色                                      |
| ------------------------------ | ----------------------------------------- |
| 品牌视觉强调、Logo箭头、栏目线 | `#4285F4`                                 |
| 按钮、文本链接                 | `#2466D3`，为小字与白底按钮提供更高对比度 |
| 悬停                           | `#1854B8`                                 |
| 标题、主要文字                 | `#262626`                                 |
| 辅助文字                       | `#626B77`                                 |
| 页面底色                       | `#FFFFFF`                                 |
| 浅灰模块                       | `#F5F7F9`                                 |
| 浅蓝重点模块                   | `#EDF4FF`                                 |

改动集中在 `src/app/theme.css` 与 `src/app/marketing.css`：减少大圆角与阴影，改用细边线和蓝色栏目标识，收紧首页引导区，统一图书、会员、社区、表单与浮窗配色。保留FDE前线的F字与上升箭头结构；同步调整favicon和默认Open Graph图的代码颜色。

真实内容图片、书封和作者照片保持原色。社群mock状态、内容、支付配置、数据及路由不变。原来的teal命名CSS变量作为蓝色别名兼容已有组件；以后调色优先修改theme.css开头的 `--brand-blue*` 变量。

验收包含生产构建、Lint、既有7条浏览器回归、桌面/手机预览与主要页面的WCAG AA自动检查。没有为纯样式修改增加重复业务测试。
