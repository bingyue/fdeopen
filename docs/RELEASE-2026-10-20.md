# FDE前线正式部署记录

目标为腾讯云 Server-Shanghai，公网域名 `https://fdeopen.com`。`www` 和 HTTP 统一跳转到 HTTPS 主域名。

## 部署

- Next.js 独立包和 PostgreSQL 17 由 Docker Compose 运行，认证模式为 `APP_MODE=postgres`，无需 Supabase。
- 应用以 UID 1001 运行，仅绑定宿主机 127.0.0.1:3215；PostgreSQL 不映射宿主机端口。
- Web 使用独立的非超级用户 `fdeopen_app`。集群管理员密码、应用数据库密码、Cron 密钥分别保存于服务器 root 专用环境文件，不进入仓库和镜像构建参数。
- 正式数据库导入 201 篇媒体内容、114 张图片、5 个媒体专题；没有创建演示用户。
- 管理员账号由服务器初始化，随机初始密码通过本地受保护文件交付。可在工作台个人资料中修改，修改后撤销全部会话。
- Let's Encrypt 证书覆盖主域名和 www，初次有效期至 2027-01-18。自动续期模拟已成功。

## 运维

运行配置位于 `/etc/fdeopen/server.env`，当前发布目录为 `/opt/fdeopen/current`。版本目录保存在 `/opt/fdeopen/releases/`；具体镜像版本以环境文件和 `docker compose ps` 为准。

`fdeopen-backup.timer` 每日创建数据库和上传卷备份；首次备份路径为 `/var/backups/fdeopen/20261020T083734Z`，已完成恢复验证。当前备份仍在同一服务器，异地备份需另行配置。`fdeopen-github-sync.timer` 使用容器内的 Cron 密钥定期刷新公开项目元数据。

不要删除 `fdeopen_postgres_data` 与 `fdeopen_uploads` 卷。更新步骤和回滚方式见 [Docker 部署说明](../deploy/server-shanghai/README.md)。
