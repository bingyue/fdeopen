# 用户体验 P0 改善 · 2026-10-25

本轮范围：首次访问入口、20 篇公开案例、动手实践、收藏与阅读连续性、登录与密码找回。

## 交付

- 首页和社区提供企业、开发者、新人三条路线；全站增加社区快捷导航。`/start` 指向具体案例、练习与共创任务。
- 公开案例仍为 20 篇。六篇结构化案例重新编辑，修复截断、错配和重复；十四篇报告/访谈案例整理标题与阅读提示，保留来源、页码与成果边界。长正文不再重复展示结构化详情。
- `/practice` 提供三份 MIT 许可本地练习包，含合成输入、标准库 Python 脚本、独立预期输出和验收模板。练习不调用模型，不声称复现客户系统。`python3 scripts/package-practice.py` 可重建 ZIP；`run.py --check` 验证示例。
- 媒体与社区收藏统一显示在工作台；登录后的阅读记录仅本人可见，最多 100 条，可关闭、清空。下架、未发布、未来定时发布的文章不会通过收藏或历史泄露。
- 登录保留经验证的本地返回路径；首次登录提供可跳过的指引。原生账号注册返回一次性恢复码，已有账号可使用当前密码生成/替换。码只存 SHA-256，恢复后立即作废并撤销全部会话；正常改密和管理员重置也会作废旧恢复码。没有密码或恢复码的存量账号仍需管理员核验归属，不提供不安全的自助重置。
- Next.js / eslint-config-next 升级至 16.4.3，Zod 至 4.6.7，修复依赖审计发现的已知安全问题。参考 [Next.js 公告](https://github.com/advisories/GHSA-2464-fhr4-w9xw)、[Zod 公告](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)。

## 发布与内容保护

先创建数据库与上传目录备份，再用新版本 tools 镜像执行：

```sh
node --import tsx scripts/migrate.ts
node --import tsx scripts/polish-cases.ts --database --owner=<管理员 UUID>
node --import tsx scripts/polish-cases.ts --database --owner=<管理员 UUID> --apply
```

迁移 009 为增量迁移。案例脚本对比审阅时的内容摘要，遇到后台编辑冲突则整批回滚并报错；不会静默覆盖 CMS 修改。原文写入管理员审计记录，重复执行无变化。状态、作者、来源、封面、收藏等不由精修脚本改写。

回滚应用可恢复上一版镜像；新增数据库字段可保留。若需恢复精修前正文，从该批 `media.cases.polish` 审计记录或发布前备份按管理员流程恢复，不回退业务库中上线后的用户数据。
