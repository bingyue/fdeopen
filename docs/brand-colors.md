# FDE前线品牌配色

页面配色从现有 Logo 的 F 字母、外框与上扬箭头延伸。主题入口为 `src/app/theme.css`。

| 色彩     | 色值      | 页面用途                                    |
| -------- | --------- | ------------------------------------------- |
| 品牌墨蓝 | `#14243B` | Logo 主体、标题、主要按钮、企业入口、页脚   |
| 箭头青绿 | `#16705F` | Logo 箭头、链接、选中态、栏目强调、键盘焦点 |
| 薄荷浅色 | `#A3DCC7` | 墨蓝背景上的图标、提示文字和焦点            |
| 墨蓝浅底 | `#EEF2F6` | 次级导航、资源图标、辅助卡片                |
| 青绿浅底 | `#EDF6F2` | 开发者入口、实践提示、选中背景              |
| 阅读底色 | `#FAFBFD` | 页面背景，搭配白色内容卡片                  |

- 优先使用 `--brand-*` 变量；`--blue` 等旧变量是兼容别名，避免旧组件恢复成亮蓝色。
- 主要操作用墨蓝，青绿用于强调；不再用紫、粉、橙区分普通资源卡片。
- 成功、警告、错误继续使用独立的语义颜色，配合文字表达状态。
- 深色背景使用白色正文、浅薄荷强调色；避免直接使用深青绿小字。
- Logo 字标复用 `LogoMark`；浏览器图标及分享图片对应 `src/app/icon.svg` 和 `src/app/opengraph-image.tsx`，调整品牌时同步检查。
