# FDE 前线媒体升级工作记录

目标依据：用户提供的《FDEOpen.com 网站全面升级 Goal》（2026-10-19）。本文记录实现与验收，不以现有测试替代目标要求。

## 现状与架构判断

- 当前版本 b1318a6，Next.js 16 / React 19 / TypeScript / Tailwind，App Router 与服务端 SQL；开发使用 PGlite，正式环境使用 PostgreSQL + Supabase Auth。
- 已有 resources、用户/个人资料、收藏、讨论、投稿审核、共创任务、专题、通知、审计日志、限流与 GitHub 数据同步。
- 首页以开源资源导航为中心。缺少媒体发布状态、作者与栏目、可排序封面推荐、企业案例字段、报告权限、媒体线索保存。
- 保留原认证与所有社区表。新增 media_* 表独立承载媒体业务，复用数据库适配器、Origin 校验、审计与限流。
- 作者/编辑权限通过 media_staff 授权，避免更改社区 role 枚举或扩大社区管理员权限。
- 文章用安全 Markdown 渲染，后台正文不执行 MDX/JSX。文件上传限类型、大小、验证真实签名；受限报告通过服务端授权下载。
- 已记录开发服务器热更新异常（.data/diagnostics/2026-10-19-dev-refresh）。浏览器服务保持停止；验证采用有结束条件的隔离环境，最终不留后台服务。

## 旧功能与新导航映射

| 已有路由 | 新入口 | 迁移策略 |
| --- | --- | --- |
| /projects、/skills、/scenarios、/lab、/build | FDE生态 → 开放社区 | 原 URL 与数据保持 |
| /developers、/developers/[handle] | FDE生态 → 专家网络 | 保留资料与公开授权 |
| /docs、/docs/[slug]、/collections | 开放社区 → 资源与开放文档 | 保留原 URL，不混写媒体文章 |
| /submit、/dashboard、登录/OAuth | 社区投稿、个人中心 | 保留权益与操作流程 |
| /admin | 内容管理入口 + 原社区运营后台 | 增加媒体后台入口，旧 tab 可继续访问 |
